# 安心陪行 SafeWalk — 助老出行服务网站

> 浙传 VIDI 实验室国创赛项目 · 助老小工具开发

## 项目简介

针对**不会使用智能手机的老人**，提供一套简单易用的出行服务网站。网站采用大字体、高对比度、照片式布局，让老人和家属都能轻松理解服务内容。

## 功能模块

| 模块 | 说明 |
|------|------|
| 出行陪护 | 专人陪同老人乘坐公共交通、就医、购物 |
| 用药提醒 | 定时提醒吃药，自动录入药品信息 |
| 安全守护 | GPS 定位、一键 SOS 紧急求助 |
| 反诈提醒 | 面向老人的常见诈骗场景提示 |
| 子女远程 | 家属端可远程查看老人状态 |
| 紧急求助 | SOS 环形按钮，按下即通知家属 |

## 设计亮点

1. **新手引导**：首次打开自动播放 5 步引导，用白色光圈高亮每个功能按钮，老人一眼就知道点哪里
2. **照片拼贴 Hero 区**：六张真实助老场景照片入场动画，右侧白色蒙版放标题
3. **反诈绿幕弹入**：左侧半透明绿色遮罩从左边弹出，醒目提示反诈内容
4. **SOS 按压动画**：环形 SOS 按钮有被按下的视觉反馈
5. **响应式布局**：手机/平板/电脑都能正常显示，窄屏自动变单列

## 技术栈

- 纯 HTML + CSS + JavaScript，无框架、无构建工具
- 7 个页面：1 个主页 + 6 个子服务页
- 本地图片素材，相对路径引用
- 右下角悬浮按钮组（语音播报 / 打印 / 字体大小 / 返回顶部）
- 接入腾讯元器 AI 客服

## 设计思路（独立思考部分）

### 项目框架怎么搭的

网站采用「主页 + 子服务页」结构：主页用照片拼贴做视觉冲击，下方纵向排列六大服务卡片，每张卡片左右交错（照片左/文字右、照片右/文字左），避免单调。底部是深蓝色邮件订阅区。

### 哪些是 AI 写的，哪些融入了我的思考

- **AI 生成**：基础页面结构、CSS 样式框架、各板块排版
- **我的思考与改进**：
  - 配色方案：主色深蓝 `#3949ab`，底部邮件区用更深的 `#2c6e9b`，绿色 `#43a047` 用于反诈和按钮——这些是我对着色板逐个确认的
  - 新手引导流程：我要求做 5 步引导、白色光圈高亮、"跳过"按钮，并且要求引导期间不能白屏
  - 动画形式：照片入场从左滑入、服务板块文字从下缓缓滑上、反诈绿幕弹入、SOS 按压效果——这些是我指定要的效果
  - Hero 区照片拼贴布局：三上三下六张照片，右侧白色蒙版
  - 修复了引导结束后照片左移、罩幕闪白条、滚动条残留等细节 bug

### 我觉得最好的功能

**新手引导系统**。老人不会用智能手机，最需要的就是"告诉他们每个按钮是干嘛的"。5 步引导走完，老人就知道：logo 在哪、服务项目在哪、联系我们在哪、了解更多按钮在哪、AI 客服在哪。这比任何文字说明都直观。

```
├── 安心陪行.html      # 主页
├── 出行陪护.html
├── 用药提醒.html
├── 安全守护.html
├── 反诈提醒.html
├── 子女远程.html
├── 紧急求助.html
├── assets/           # 图片素材
└── README.md
```
